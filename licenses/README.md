# Standard license texts

These verbatim standard texts come from the SPDX License List data,
[tag v3.28.0](https://github.com/spdx/license-list-data/tree/v3.28.0/text).
They supplement, and do not replace, individual packages' copyright and license notices.
Templates containing generic copyright placeholders are not TopoSky copyright claims.

The [production dependency inventory](../THIRD_PARTY_NOTICES.md) records each locked package's
license expression. `npm run notices:bundle` combines installed production-package notices
with these texts for the build platform. Distributors must review upstream attribution and
corresponding-source requirements; the files are not a legal compliance certification.
